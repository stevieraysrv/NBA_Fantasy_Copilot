PRODUCT OVERVIEW / YAHOO API REVIEW

Fantasy NBA Copilot

A personal basketball analytics companion for a single Yahoo Fantasy H2H nine-category league. Compare team projections, explore category strengths, and model the impact of possible waiver pickups and trades before deciding what to do in Yahoo Fantasy.

CURRENT IMPLEMENTATION

This is a working, browser-local demonstration with 10 fictional teams, 130 fictional players, and synthetic projections. It makes no Yahoo API requests, has no Yahoo sign-in, and does not collect account credentials. OAuth integration is planned after API access approval. No access or endorsement has been granted or implied.

Try the demo

  1. Choose an analyzed team in “Analizirana ekipa” and an opponent in “Usporedi s”. Review category ranks and the season H2H comparison.
  2. Change the chart category and edit a player projection in “Roster & projekcije”. Analysis updates immediately; shooting percentages are weighted by attempts.
  3. Scroll to “Simulacije”. Inspect the sample ADD / DROP results or enter a fictional waiver candidate. “Punt TO” controls whether turnovers count in simulations.
  4. Choose two players in the trade simulator and click “Usporedi trade”. “Primijeni lokalno” applies the scenario only inside this browser.
  5. Use “Spremi JSON” for a backup, “Uvezi JSON” to restore a validated file, or “Obriši lokalne podatke” to delete app storage. “Vrati demo podatke” restores the sample league.

Requested use and audience

The proposed integration is for the owner's personal analysis of a single league in which the owner participates. The expected initial user is one authenticated league member. It is not a public league-data service. Any expansion to other users or leagues would require reassessing the scope and applicable Yahoo requirements.

Proposed read-only data access

  • Discover the authenticated user's basketball leagues and let the user select their league.
  • Read that league's metadata, scoring settings, teams, rosters, and standings.
  • Read player statistics and league-specific player availability to support comparisons and manually initiated waiver analysis.
  • Read matchups when available to add context to the selected league.

Only read access is requested. All trade, roster, and waiver actions remain local scenarios. Users make actual lineup and transaction decisions in Yahoo Fantasy. Yahoo projections or schedules are not assumed to be available through the API; any future projection source will be identified separately.

Integration plan after approval

Use Yahoo OAuth 2.0 authorization code flow through a server-side component. The browser will redirect to Yahoo for consent; it will never ask for a Yahoo password. The backend will validate OAuth state, exchange the authorization code, keep client secrets and refresh tokens outside public files, and use secure session cookies.

The backend is not part of this demo. Before connecting real accounts, it must implement secure token storage, disconnect and deletion behavior, limited caching, error handling, and request throttling. The static GitHub Pages demo alone cannot store OAuth secrets safely.

Privacy and data handling today

All demo calculations happen in the browser. Imported files and edited projections stay in this origin's localStorage until removed. There are no analytics, advertising SDKs, cookies, remote fonts, or third-party data calls. Exports are generated locally. Browser storage is not encrypted by this app and is accessible to someone using the same browser profile.

Hosting infrastructure may process ordinary access logs. Imported JSON data is not uploaded by this app. See the current demo privacy notice.

Model boundaries

Season comparisons sum all rostered player projections, including bench players. Weekly simulations use season totals divided by 82 and multiplied by a user-entered game count. They do not account for individual schedules, injuries, lineup constraints, or playing time. Category scores are deterministic comparisons, not win probabilities.
