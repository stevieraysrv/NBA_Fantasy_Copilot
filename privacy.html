Last updated: 21 October 2026. This notice describes the current static demonstration. It does not describe an active Yahoo account integration.

What this demo handles

The app includes synthetic team and player data. If you import a JSON file, edit projections, or run local scenarios, the app processes team names, player names, projection values, candidates, and analysis settings in your browser. It does not request Yahoo account details or OAuth credentials.

Storage and retention

The app saves state under fantasyCopilotV4 in localStorage. It may read prior-version keys fantasyTeamsV1 and waiverCandidatesV3 to migrate valid data. Data stays until you delete it or your browser clears it. It is not synchronized between devices. It is not encrypted by this app, and others using your browser profile may access it.

Sharing and network requests

There are no analytics, advertisements, remote fonts, or third-party data calls. Imported JSON files are read locally. The app does not upload their contents. CSV and JSON exports are generated on your device; you decide where to save or share them. Following an external link opens that provider's website under its own policies.

Your hosting provider may receive IP addresses, browser request details, and ordinary web access logs when serving the static files. This app has no application backend or database and does not control the hosting provider's retention.

Delete or export

“Spremi JSON” exports a backup of app state. “Obriši lokalne podatke” deletes the three app storage keys after confirmation and displays the original demo. You can also clear this site's storage in browser settings. Previously downloaded files and hosting logs are not deleted by this control.

Future Yahoo integration

Yahoo OAuth and server-side processing are planned, not implemented. This notice must be updated before real account integration, with operator contact details, the actual hosting and token handling, retention periods, and disconnect/deletion behavior.
