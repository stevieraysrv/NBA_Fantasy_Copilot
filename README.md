# Fantasy NBA Copilot

A personal H2H nine-category basketball analytics demo for Yahoo Fantasy Sports API review.

- [Open the dashboard](https://stevieraysrv.github.io/NBA_Fantasy_Copilot/)
- [Product and API review overview](https://stevieraysrv.github.io/NBA_Fantasy_Copilot/review.html)
- [Privacy notice](https://stevieraysrv.github.io/NBA_Fantasy_Copilot/privacy.html)

This static demo uses fictional teams, players, and synthetic projections. It has no Yahoo OAuth integration and does not modify a Yahoo league. All calculations and imported data stay in the browser.

## Hosting

GitHub Pages, branch main, repository root. No build step or third-party dependencies.

## Support

Use this repository's issue tracker. Do not post private league data or credentials.
